# 调度平台元数据解析

## 1. Agent元数据

* agent_info表
  * AGENT_ID：每个Agent独有的ID
  * AGENT_NAME：Agent名称
  * AGENT_TYPE：
    * 4：FILE_AGENT/S3-AGENT
    * 1：DB-AGENT
    * 3：FTP-AGENT
  * AGENT_IP
  * AGENT_PORT
  * AGENT_STATUS：
    * 2：停止
    * 1：运行
  * AGENT_STORAGE_TYPE：
    * 1：Nas
    * 2：S3
* agent_down_info表
  * AGENT_NAME
  * AGENT_IP
  * AGENT_PORT
  * USER_NAME
  * PASSWD（密文）
  * SAVE_DIR：部署目录
  * LOG_DIR：运行日志目录
  * DEPLOY：
    * 1：开启自动启动
    * 2：关闭自动启动
  * AGENT_ID
  * AGENT_TYPE（同agent_info表）

## 2. 批次元数据和源系统连接配置元数据

* batch_info表
  * BATCH_ID：批次id
  * DATABASE_ID：数据库id，特指源系统数据库
  * SOURCE_ID：数据源id，用于提取系统号
  * BATCH_NUMBER：批次号
  * BATCH_DESC：批次描述
  * IS_EXP：是否从数据库抽数
  * EXP_DIR：源系统数据落地目录
* batch_relation_table表：主要存储BATCH_ID和TABLE_ID用于批次与表建立关联
* database_set表
  * DATABASE_ID：数据库id
  * AGENT_ID：Agent编号
  * TASK_NAME：源连接名称
  * DATABASE_NAME：源系统数据库名称
  * DATABASE_PAD：源系统数据库密码（暗文）
  * DATABASE_DRIVE：数据库jdbc驱动
  * DATABASE_TYPE：数据库类型
  * USER_NAME：数据库用户名
  * DATABASE_IP：数据库IP
  * DATABASE_PORT：数据库端口号
  * DB_AGENT：是否为DB_AGENT
  * PLANE_URL：数据落地路径
  * JDBC_URL
  * AGENT_TYPE：Agent类型

## 3.工程元数据

* etl_sys_cd表：主要存储工程信息、工程状态监控、工程Agent部署机器信息、部署路径等
* etl_sys_dependency表：主要存储工程间依赖关系和依赖有效状态
* etl_sub_sys_list表：主要用于存储工程下子工程的信息、备注

## 4. 作业元数据

* etl_job_def表
  * ETL_JOB：作业名
  * ETL_SYS_CD：作业所属工程名
  * SUB_SYS_CD：作业所属子工程名
  * ETL_JOB_DESC：作业描述
  * PRO_TYPE：作业执行程序类型
    * SHELL
    * PERL
    * JAVA
    * PYTHON
  * PRO_DIC：作业执行程序目录
  * PRO_NAME：作业执行程序名称
  * PRO_PARA：作业输入参数
  * LOG_DIC：作业日志路径
  * DISP_FREQ：作业调度频率
    * D：自然日
    * G：工作日
    * M：月
    * W：周
    * X：旬
    * Y：年
  * DISP_OFFSET：作业偏移量（0为当天，正为未来，负为过去）
  * DISP_TYPE：触发方式
    * D：依赖触发
    * T：T+1日定时触发
    * Z：T+0日定时触发
  * DISP_TIME：调度时间
  * JOB_EFF_FLAG：作业有效标识
    * Y：有效
    * N：无效
    * V：空跑
  * JOB_PROIORITY：作业优先级
  * TODAY_DISP：是否今日调度
* etl_dependency表：主要存储作业系统名、作业名、上游作业系统名、上游系统作业名和依赖有效状态
* etl_job_cur表：主要存储当前作业的作业信息和状态，字段基本同def表，方便control和trigger读取作业信息
* etl_job_disp_his表：存储已调度作业的历史信息，主要字段同def表
* etl_job_hand表：疑似强制执行的干预记录
* etl_job_hand_dep表：疑似带依赖重跑的干预记录
* etl_job_hand_his表：存储作业干预历史记录，包括作业信息、干预类型、干预状态、开始和结束时间
* etl_job_resource_rela表：单个作业的分配资源类型和分配资源数
* etl_para表：按工程存储的作业参数映射值，如日志路径、批次日期等
* etl_resource表：按工程存储的作业资源类型分配总资源数信息表
* holiday_run_job表：存储下游作业需自然日调度但当前为工作日调度的表信息和对应工程名（因为非工作日调度工作日作业trigger会直接略过不启动作业）

## 5. 采集表信息元数据

* table_info表
  * TABLE_ID
  * TABLE_SCHEMA：源表模式名
  * TABLE_NAME：源表英文名
  * TABLE_CH_NAME：源表中文名
  * TABLE_DESC：源表描述
  * DATABASE_ID：数据库ID，用于关联源连接数据库表（database_set）
  * UNLOAD_TYPE：卸数条件，1全量，2增量
  * TABLE_SQL：抽数条件（增量独有）
  * IMP_TABLE_NAME：入库表名
  * PARTITION_FIELDS：分区字段（分区未启用）

* table_column表
  * COLUMN_ID：字段ID
  * IS_PRIMARY_KEY：是否为主键，Y是，N否（主键专供F2和F3算法）
  * COLUMN_NAME：源表字段名
  * COLUMN_TYPE：源表字段类型
  * COLUMN_CH_NAME：源表字段中文名
  * TABLE_ID：用于关联table_info等表
  * DCL_COLUMN_NAME：入库字段名
  * COLUMN_NUM：存入字段顺序，非常重要，如果筛选条件不包含，字段只会按照字典顺序排序

* table_datalake_rule表：数据湖规则，用于表发布和订阅模板生成导出
* table_storage_info表
  * STORAGE_ID：存储id
  * STORAGE_TYPE：存储类型
    * 3：F1全表覆盖
    * 7：F2Upsert加载
    * 6：F3历史拉链增量加载
    * 4：F5历史拉链全量加载
    * 2：I流水表增量加载

  * IS_ZIPPER：是否拉链表
  * HYREN_NAME：入库hive表名
  * TABLE_ID

* tbcol_srctgt_map表
  * COLUMN_ID
  * DSL_ID
  * COLUMN_TAR_TYPE：入库字段类型（单表查询或关联后按条件查询会走索引，字段值显示不全；关联后或全表扫描会返回正常字段值）


## 6. 加工表元数据

* dm_info表：主要存储集市层信息BAS、IDX、ADI
* dm_datatable表
  * DATATABLE_ID：数据库id
  * DATA_MART_ID：集市id
  * DATATABLE_CN_NAME：加工表中文名
  * DATATABLE_EN_NAME：加工表英文名
  * DATATABLE_DESC：加工表描述
  * STORAGE_TYPE：进数类型
  * PARTITION_FIELDS：分区字段
  * CATEGORY_ID
* dm_datatable_source表
  * OWN_DOURCE_TABLE_ID：上游表id
  * DATATABLE_ID：加工表id
  * OWN_SOURCE_TABLE_NAME：上游表名
  * SOURCE_TYPE：源表类型（意义不明：DCL、DML、UDL）
* dm_job_info表
  * JOB_ID：作业表id
  * DATATABLE_ID：加工表id
  * JOB_NUMBER：作业表名称
  * JOB_NAME：作业表中文名
  * JOB_DESC：作业表描述
* dm_etlmap_info表
  * ETL_ID：（意义不明）
  * DATATABLE_ID
  * OWN_DOURCE_TABLE_ID
  * TARGETFIELD_NAME：目标字段名
  * D/SOURCEFIELDS_NAME：源字段名
* dm_category表
  * CATEGORY_ID：主题id
  * CATEGORY_NAME：主题名
  * CATEGORY_DESC：主题描述
  * CATEGORY_NUM：主题编号
  * PARENT_CATEGORY_ID：父主题id
  * DATA_MART_ID：数据集市id
* dm_operation_info表
  * ID
  * DATATABLE_ID
  * VIEW_SQL：预览SQL
  * EXECUTE_SQL：执行SQL
  * VERSION_DATE：SQL创建日期
* dm_relation_job表
  * JOB_ID
  * DATATABLE_ID
  * IS_TEMP：是否是临时表
  * SETP_NUMBER：步骤序号
  * ID
* dm_operation_info_version表：存储加工SQL历史

## 7. 数据导出元数据

* data_distribute表
  * SQL_TABLE：数据导出SQL逻辑
  * IS_HEADER：
    * 0：不带表头
    * 1：带表头
  * DATABASE_SEPARATORR：列分隔符——!^
  * PLANE_URL：数据落地目录
  * FILE_NAME：文件名称
  * FILE_SUFFIX：文件后缀
  * IS_UPPER：文件名是否大写
  * IS_COMPRESS：是否压缩
  * IS_FLAG：是否附带标识文件
  * FLAG_SUFFIX：标识文件后缀（默认flag）
  * IS_RELEASE：是否推送后删除本地文件
  * TRANS_MODE：传输类型
    * ESB
    * FTP
    * OBS
    * S3
    * SFTP
  * REL_PATH：推送路径
  * FILE_CN_NAME：文件中文名
  * FILE_GROUP：文件分组
* dtsst_trns_mthd表：主要用于存储传输方式和对应连接信息

## 8. 系统表

* sys_para表：非常重要，主要用于存储调度平台基本信息、参数、路径和脚本程序调用的参数及路径，涉及容器的参数需重启容器后加载

* data_store_layer_attr：主要存储MRS配置文件位置、hive驱动、集群租户信息和jdbc_url
* sys_holiday表：主要用于存储节假日，定期维护
* sys_warn表：主要存储作业报错信息，用于短信报警
