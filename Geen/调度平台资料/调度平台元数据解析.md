# 调度平台元数据解析

## 1. Agent元数据

* agent_info表
  * AGENT_ID：每个Agent独有的ID
  * AGENT_NAME：Agent名称
  * AGENT_TYPE：
    * 4：FILE_AGENT/S3-AGENT
    * 1：DB-AGENT
    * 3：FTP-AGENT
  * AGENT_IP
  * AGENT_PORT
  * AGENT_STATUS：
    * 2：停止
    * 1：运行
  * AGENT_STORAGE_TYPE：
    * 1：Nas
    * 2：S3
* agent_down_info表
  * AGENT_NAME
  * AGENT_IP
  * AGENT_PORT
  * USER_NAME
  * PASSWD（密文）
  * SAVE_DIR：部署目录
  * LOG_DIR：运行日志目录
  * DEPLOY：
    * 1：开启自动启动
    * 2：关闭自动启动
  * AGENT_ID
  * AGENT_TYPE（同agent_info表）





## 2. 批次元数据和源系统连接配置元数据

* batch_info表
  * BATCH_ID：批次id
  * DATABASE_ID：数据库id，特指源系统数据库
  * SOURCE_ID：数据源id，用于提取系统号
  * BATCH_NUMBER：批次号
  * BATCH_DESC：批次描述
  * IS_EXP：是否从数据库抽数
  * EXP_DIR：源系统数据落地目录
* batch_relation_table表：主要存储BATCH_ID和TABLE_ID用于批次与表建立关联
* database_set表
  * DATABASE_ID：数据库id
  * AGENT_ID：Agent编号
  * TASK_NAME：源连接名称
  * DATABASE_NAME：源系统数据库名称
  * DATABASE_PAD：源系统数据库密码（暗文）
  * DATABASE_DRIVE：数据库jdbc驱动
  * FETCH_SIZE：数据库类型
  * USER_NAME：数据库用户名
  * DATABASE_IP：数据库IP
  * DATABASE_PORT：数据库端口号
  * DB_AGENT：是否为DB_AGENT
  * PLANE_URL：数据落地路径
  * JDBC_URL
  * AGENT_TYPE：Agent类型

## 3.工程元数据

* etl_sys_cd表：主要存储工程信息、工程状态监控、工程Agent部署机器信息、部署路径等
* etl_sys_dependency表：主要存储工程间依赖关系和依赖有效状态
* etl_sub_sys_list表：主要用于存储工程下子工程的信息、备注

## 4. 作业元数据

* etl_job_def表
  * ETL_JOB：作业名
  * ETL_SYS_CD：作业所属工程名
  * SUB_SYS_CD：作业所属子工程名
  * ETL_JOB_DESC：作业描述
  * PRO_TYPE：作业执行程序类型
    * SHELL
    * PERL
    * JAVA
    * PYTHON
  * PRO_DIC：作业执行程序目录
  * PRO_NAME：作业执行程序名称
  * PRO_PARA：作业输入参数
  * LOG_DIC：作业日志路径
  * DISP_FREQ：作业调度频率
    * D：自然日
    * G：工作日
    * M：月
    * W：周
    * X：旬
    * Y：年
  * DISP_OFFSET：作业偏移量（0为当天，正为未来，负为过去）
  * DISP_TYPE：触发方式
    * D：依赖触发
    * T：T+1日定时触发
    * Z：T+0日定时触发
  * DISP_TIME：调度时间
  * JOB_EFF_FLAG：作业有效标识
    * Y：有效
    * N：无效
    * V：空跑
  * JOB_PROIORITY：作业优先级
  * TODAY_DISP：是否今日调度
* etl_dependency表：主要存储作业系统名、作业名、上游作业系统名、上游系统作业名和依赖有效状态
* etl_job_cur表：主要存储当前作业的作业信息和状态，字段基本同def表，方便control和trigger读取作业信息
* etl_job_disp_his表：存储已调度作业的历史信息，主要字段同def表
* etl_job_hand表：疑似强制执行的干预记录
* etl_job_hand_dep表：疑似带依赖重跑的干预记录
* etl_job_hand_his表：存储作业干预历史记录，包括作业信息、干预类型、干预状态、开始和结束时间
* etl_job_resource_rela表：单个作业的分配资源类型和分配资源数
* etl_para表：按工程存储的作业参数映射值，如日志路径、批次日期等
* etl_resource表：按工程存储的作业资源类型分配总资源数信息表
* holiday_run_job表：存储下游作业需自然日调度但当前为工作日调度的表信息和对应工程名（因为非工作日调度工作日作业trigger会直接略过不启动作业）

## 7. 数据导出元数据

* data_distribute表
  * SQL_TABLE：数据导出SQL逻辑
  * IS_HEADER：
    * 0：不带表头
    * 1：带表头
  * DATABASE_SEPARATORR：列分隔符——!^
  * PLANE_URL：数据落地目录
  * FILE_NAME：文件名称
  * FILE_SUFFIX：文件后缀
  * IS_UPPER：文件名是否大写
  * IS_COMPRESS：是否压缩
  * IS_FLAG：是否附带标识文件
  * FLAG_SUFFIX：标识文件后缀（默认flag）
  * IS_RELEASE：是否推送后删除本地文件
  * TRANS_MODE：传输类型
    * ESB
    * FTP
    * OBS
    * S3
    * SFTP
  * REL_PATH：推送路径
  * FILE_CN_NAME：文件中文名
  * FILE_GROUP：文件分组
* dtsst_trns_mthd表：主要用于存储传输方式和对应连接信息

## 8. 系统表

* sys_para表：非常重要，主要用于存储调度平台基本信息、参数、路径和脚本程序调用的参数及路径，涉及容器的参数需重启容器后加载

* data_store_layer_attr：主要存储MRS配置文件位置、hive驱动、集群租户信息和jdbc_url
* sys_holiday表：主要用于存储节假日，定期维护
* sys_warn表：主要存储作业报错信息，用于短信报警
