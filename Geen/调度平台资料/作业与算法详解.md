# 作业与算法详解

## 1. 数据采集作业

### 1.1 exp作业（抽数）(DB-Agent专属)

* 读取源系统数据库配置并连接数据库

* 数据清洗替换（未使用）

* 读取元数据获取模式名、表名、字段名、字段中文名、字段类型和增量条件（增量表专用）并生成查询SQL

* 确定数据落地目录（不存在则创建）、数据文件名称（.dat）、字段数量

* 数据分批抽取并落地



### 1.2 ddl作业（生成ddl文件）(DB-Agent/FTP-Agent专属)

* 根据元数据获取并生成作业状态json文件并保存在Agent对应路径下
* 根据ddl配置文件生成tab、flag、col等数据文件元数据和统计信息文件



### 1.3 signal_check作业（检查flag文件）

#### 1.3.1 S3-Agent

* 根据生成的metaBatch文件获取S3路径和配置信息
* 检测S3文件是否存在并S3下载数据文件至本地路径（cols、flag、tabs、dat）
* 获取下载文件数量、数据文件数量并对比flag文件数量与实际文件数量是否一致

#### 1.3.2 其他Agent

* 检测flag文件是否存在，不存在60秒后重新检测（直接用wc检测文件大小，文件大小和win系统展示大小不同，通常差几个字节）



### 1.4 metavalid作业（元数据校验）

* 校验系统信息、获取批次、数据文件数量、获取标志文件信息、核对flag文件数量
* 检测核对tabs、cols与dat中的表结构、字段信息是否一致，不一致则返回报错



### 1.5 S3作业（数据文件上传S3）

* 上传dat文件至数据湖S3，如果资产未发布会报错



### 1.6 hdfsFile_check作业（hdfs文件检查）

* 检测数据湖是否下发flag文件至hdfs，未下发则每12秒检测一遍，超时时间为3600秒



### 1.7 load作业（数据入表）

* 查询sdi表是否存在
* 创建sdi表，必须是text格式
* load命令加载数据文件至sdi表

* 加载成功后删除flag文件，便于数据湖重复推送（flag文件存在数据湖不下发）
* 删除S3路径的dat文件



### 1.8 his作业（历史化）

* 查询源表和字段信息、入库表和字段信息、进数算法
* 更新作业调度历史表
* 判断目标表是否存在、是否有数据（否则报错弹出手动建表）、判断回滚表和批次自动备份表是否存在（存在则退出，手动清除后再重新跑批，避免作业非正常结束临时表覆盖目标表数据）
* 清除并创建current表，将sdi表当天数据导入进current表
* 检查目标表和临时表的元数据和数据文件是否一致，如果元数据不存在而数据文件存在则删除数据文件，确保跑批正常插入数据
* spark-submit提交python脚本运行历史化SQL，根据返回码判断作业结果，错误则抓取application_id，便于查询yarn日志
* 更新作业和事件状态，如果报错则更新报错表便于短信报警
* 删除所有临时表
* 更新Impala元数据信息



## 2. 加工作业和导出作业

### 2.1 process作业（加工作业）

* 获取表信息、字段信息、算法、依赖、步骤顺序等元数据信息
* 确定业务字段和技术字段
* 确定表是否存在、是否有当天新增数据和闭链数据（确定是否为重跑决定需不需要回滚）
* 查询加工作业并发数（默认为3）和当前作业历史状态，避免重复提交
* 开始执行步骤，查询字段信息，并清理临时表生成创建步骤表（中间步骤临时表或目标表）和不同算法所需临时表语句
* 生成加工SQL和历史化算法SQL（中间表默认F1全表覆盖）
* 检查目标表和临时表的元数据和数据文件是否一致，如果元数据不存在而数据文件存在则删除数据文件，确保跑批正常插入数据
* spark-submit提交python脚本运行历史化SQL，根据返回码判断作业结果，错误则抓取application_id，便于查询yarn日志
* 更新作业状态表，如果报错则更新报错表便于短信报警
* 删除所有临时表
* 更新Impala元数据信息



### 2.2 数据导出作业

#### 2.2.1 distri作业（抽取落地）

* 查询数据导出SQL语句
* 检查数据落地目录，不存在则创建
* spark-submit提交数据导出SQL
* 从hdfs下载数据文件
* 统计数据文件行数

#### 2.2.2 detrans作业（文件推送）

* 获取目标系统的配置信息，如S3、OBS、ESB、FTP等
* 推送本地dat文件，如勾选不保留本地文件则推送后删除本地文件

### 2.3 F2——Upsert增量

```sql
-- 创建目标表
CREATE TABLE IF NOT EXISTS sdf_SXX_XXXXXXXX(...)
STORED AS PARQUET TABLPROPERTIES('parquet.compression'='snappy')

-- 清理旧拉链表并重新建表
DROP TABLE IF EXISTS sdf_SXX_XXXXXXXX_zipper purge

CREATE TABLE IF NOT EXISTS sdf_SXX_XXXsdf_SXX_XXXXXXXX_zipper(...)
STORED AS PARQUET TABLPROPERTIES('parquet.compression'='snappy')

-- 清理旧current表并重新建表
DROP TABLE IF EXISTS sdf_SXX_XXXXXXXX_current purge

CREATE TABLE IF NOT EXISTS sdf_SXX_XXXXXXXX_current(...)
STORED AS PARQUET TABLPROPERTIES('parquet.compression'='snappy')

-- sdi数据插入current表
INSERT INTO sdf_SXX_XXXXXXXX_current SELECT ...
'his_SXX_XX_XXXXXXXX' AS ETL_JOB_NM,
'XXXXXXX' AS ETL_TBL_NM,
'2025-03-03 10:11:10' AS ETL_UPD_TM,
'2025-03-03' AS DATA_INSR_DT,
MD5(CONCAT(CAST(NVL(..., '') AS STRING), '',...)) AS HYREN_MD5_VAL -- 这里是主键+空字符串拼成字符串后计算MD5值
FROM sdf_SXX_XXXXXXXX_20250303

-- 清理batchautorestoreback表并备份原表
DROP TABLE IF EXISTS sdf_SXX_XXXXXXXX_batchautorestoreback purge
ALTER TABLE sdf_SXX_XXXXXXXX RENAME TO sdf_SXX_XXXXXXXX_batchautorestoreback

-- 创建目标表
CREATE TABLE IF NOT EXISTS sdf_SXX_XXXXXXXX(...)
STORED AS PARQUET TABLPROPERTIES('parquet.compression'='snappy')

-- 插入昨日数据至目标表
INSERT INTO sdf_SXX_XXXXXXXX SELECT * FROM sdf_SXX_XXXXXXXX_F2_20250302

-- 插入目标表与current表md5值不同（今日与昨日主键不同）的昨日数据进入拉链表
INSERT INTO sdf_SXX_XXXXXXXX_zipper 
SELECT * FROM sdf_SXX_XXXXXXXX 
WHERE NOT EXISTS (SELECT 1 FROM sdf_SXX_XXXXXXXX_current WHERE sdf_SXX_XXXXXXXX.HYREN_MD5_VAL = sdf_SXX_XXXXXXXX_current.HYREN_MD5_VAL)

-- 插入今日数据至拉链表
INSERT INTO sdf_SXX_XXXXXXXX_zipper
SELECT * FROM sdf_SXX_XXXXXXXX_current

-- 清理batchoutoback表、备份原表并用拉链表覆盖原表
DROP TABLE IF EXISTS sdf_SXX_XXXXXXXX_batchautoback purge
ALTER TABLE sdf_SXX_XXXXXXXX RENAME TO sdf_SXX_XXXXXXXX_batchautoback
ALTER TABLE sdf_SXX_XXXXXXXX_zipper RENAME TO sdf_SXX_XXXXXXXX

-- 创建今日对比备份表并将进入数据插入对比表
CREATE TABLE IF NOT EXISTS sdf_SXX_XXXXXXXX_F2_20250303(...)
STORED AS PARQUET TABLPROPERTIES('parquet.compression'='snappy')

INSERT INTO sdf_SXX_XXXXXXXX_F2_20250303 SELECT * FROM sdf_SXX_XXXXXXXX
```



### 2.4 F3——历史拉链增量

```sql
-- 创建目标表
CREATE TABLE IF NOT EXISTS sdf_SXX_XXXXXXXX_h(...)
STORED AS PARQUET TABLPROPERTIES('parquet.compression'='snappy')

-- 清理旧拉链表并重新建表
DROP TABLE IF EXISTS sdf_SXX_XXXXXXXX_zipper purge

CREATE TABLE IF NOT EXISTS sdf_SXX_XXXsdf_SXX_XXXXXXXX_zipper(...)
STORED AS PARQUET TABLPROPERTIES('parquet.compression'='snappy')

-- 清理旧current表并重新建表
DROP TABLE IF EXISTS sdf_SXX_XXXXXXXX_current purge

CREATE TABLE IF NOT EXISTS sdf_SXX_XXXXXXXX_current(...)
STORED AS PARQUET TABLPROPERTIES('parquet.compression'='snappy')

-- sdi数据插入current表
INSERT INTO sdf_SXX_XXXXXXXX_current SELECT ...
'his_SXX_XX_XXXXXXXX' AS ETL_JOB_NM,
'XXXXXXX' AS ETL_TBL_NM,
'2025-03-03 10:11:10' AS ETL_UPD_TM,
'2025-03-03' AS STRT_DT,
'9999-12-31' AS END_DT,
MD5(CONCAT(CAST(NVL(..., '') AS STRING), '',...)) AS HYREN_MD5_VAL -- 这里是主键+空字符串拼成字符串后计算MD5值
FROM sdf_SXX_XXXXXXXX_20250303

-- 插入原表中需要闭链的数据至拉链表，因为增量更新，主键一致的行一定需要闭链更新
INSERT INTO sdf_SXX_XXXXXXXX_zipper 
SELECT ...
'2026-03-03' AS END_DT,
...
FROM sdf_SXX_XXXXXXXX_h
WHERE EXISTS (SELECT 1 FROM sdf_SXX_XXXXXXXX_current WHERE sdf_SXX_XXXXXXXX_h.HYREN_MD5_VAL = sdf_SXX_XXXXXXXX_current.HYREN_MD5_VAL) AND sdf_SXX_XXXXXXXX_h.END_DT = '9999-12-31'

-- 插入不需要更新的原表数据进入拉链表
INSERT INTO sdf_SXX_XXXXXXXX_zipper 
SELECT *
FROM sdf_SXX_XXXXXXXX_h
WHERE NOT EXISTS (SELECT 1 FROM sdf_SXX_XXXXXXXX_current WHERE sdf_SXX_XXXXXXXX_h.HYREN_MD5_VAL = sdf_SXX_XXXXXXXX_current.HYREN_MD5_VAL) AND sdf_SXX_XXXXXXXX_h.END_DT = '9999-12-31'

-- 插入已经闭链的旧数据进入拉链表
INSERT INTO sdf_SXX_XXXXXXXX_zipper 
SELECT *
FROM sdf_SXX_XXXXXXXX_h
WHERE sdf_SXX_XXXXXXXX_h.END_DT <> '9999-12-31'

-- 插入今日数据进入拉链表
INSERT INTO sdf_SXX_XXXXXXXX_zipper SELECT * FROM sdf_SXX_XXXXXXXX_current

-- 清理batchoutoback表、备份原表并用拉链表覆盖原表
DROP TABLE IF EXISTS sdf_SXX_XXXXXXXX_batchautoback purge
ALTER TABLE sdf_SXX_XXXXXXXX_h RENAME TO sdf_SXX_XXXXXXXX_batchautoback
ALTER TABLE sdf_SXX_XXXXXXXX_zipper RENAME TO sdf_SXX_XXXXXXXX_h
```
